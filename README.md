## About The Project

**Das Grüne** is a creative design agency website concept built to practice recreating a visually bold, typography-focused landing page using HTML and CSS.

The project focuses on combining **large-scale typography, spacing, positioning, imagery, shapes, and contrasting colors** to create a distinctive visual identity.

Rather than relying on frameworks, the page was built from scratch using fundamental frontend technologies.

* Bold typography-driven hero section

## Design

The design uses a minimal but expressive visual system built around a few strong elements.

### Color Palette

| **Color**     | **Hex**   | **Usage**                       |
| ------------- | --------- | ------------------------------- |
| Lime Green    | `#D5FF3F` | Primary accent and CTA          |
| Dark Charcoal | `#171717` | Main dark sections              |
| Grey          | `#909090` | Secondary text                  |
| White         | `#FFFFFF` | Contrast and interface elements |

The lime-green and dark-charcoal combination creates the main visual identity of the page.

### Typography

Typography plays a major role in the design.

The hero uses extremely large uppercase headings to create visual impact, while the services and CTA sections continue the same typography-focused approach.

The goal was to make typography function as part of the visual design rather than simply displaying information.

## Sections

### 1. Navigation

The navigation introduces the **Das Grüne** brand and contains links for:

* About Us
* Project
* Services
* Let's Talk

### 2. Hero Section

The hero is built around the headline:

**D̈igitize IDEAS**

It combines oversized typography, supporting copy, and a visual play-button element.

### 3. Visual Banner

A large image section follows the hero and uses a circular arrow element to create a strong visual transition.

### 4. Discuss Your Ideas

A large typography-based section introduces the message:

**Discuss your ideas**

This acts as a visual break between the hero and services content.

### 5. Services

The services section presents the agency's creative capabilities through typography, buttons, icons, and structured content.

Services include:

* Design
* Development
* Digital Marketing
* SEO
* UI/UX Design
* Web Design
* Brand Design
* Graphic Design

### 6. Creative Showcase

Multiple image blocks are arranged throughout the page to create an editorial-style visual gallery.

### 7. Final CTA

The page concludes with:

**Let's Discuss Your Ideas**

alongside a **Talk Now** button, creating a clear final call-to-action.

## Challenges

One of the main challenges was translating a highly visual design into a webpage using only HTML and CSS.

The most challenging parts were working with:

* Large typography and spacing
* Absolute positioning
* Overlapping visual elements
* Image placement
* Circular UI elements
* Maintaining the intended visual composition

This project helped me understand that recreating a design is not only about writing CSS. It also requires paying attention to **spacing, proportions, hierarchy, and visual balance**.
